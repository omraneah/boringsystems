## Claude Code — Harness-specific

This section extends `AGENTS.md` with Claude Code-specific mechanics. Everything in `AGENTS.md` applies. This section adds what is unique to the Claude Code harness.

### Skills

Skills live at `.agent-skills/<name>/SKILL.md` (canonical, shared across all agents). Available to Claude Code via the `~/.claude/skills/` symlink created by setup.sh.

- Invocation: `/skill-name` slash commands.
- **New skills write to `.agent-skills/`** — this path is pre-authorized, no feature branch required.
- Setup.sh syncs `.agent-skills/` → `.agents/skills/` at session start so Codex and other agents pick up new skills.
- Do not write to `.claude/personal-skills/` — that directory no longer exists.

Cross-project skills reference: `docs/infrastructure.md` § Skills.

### Hooks

**Shared enforcement hooks** in `.agent-hooks/` (stateless, agent-agnostic — registered by all agents):
- `enforce-feature-branch.sh` — blocks edits on protected branches.
- `block-protected-push.sh` — blocks pushes to protected branches.
- `brevity-reminder.sh` — injects brevity reminder at every turn.
- `parallel-by-default-reminder.sh` — injects parallel-execution reminder on multi-task prompts.

**Claude Code-specific hooks** in `.claude/hooks/` (use `$CLAUDE_PROJECT_DIR`):
- `session-start.sh` — runs setup.sh, auto-pulls base branch, surfaces typecheck failures.
- `auto-commit.sh` — auto-commits dirty state at end of turn (Stop, async).
- `post-edit-typecheck.sh` — runs tsc/astro check on TypeScript edits (Stop, async).
- `gtm-nudge.sh` — periodic reminder to capture GTM signal (Stop, async).

All hooks registered in `.claude/settings.json` (symlinked to `~/.claude/settings.json` by setup.sh).

### Sub-agents

Sub-agents are thin wrappers at `.claude/agents/<name>.md`. Each wrapper contains only frontmatter (name, description, model, effort, tools) and `@agent-personas/<name>.md` in the body. Persona content lives in `.agent-personas/` — the canonical source.

Never edit `.codex/agents/*.toml` directly. They are generated by `scripts/generate-codex-agents.py` (runs via setup.sh).

### Setup

`bash .claude/setup.sh` on a fresh machine:
- Creates `~/.claude/skills/` → `.agent-skills/` (symlink — Claude Code reads skills from here).
- Creates `~/.claude/settings.json` → `.claude/settings.json` (symlink).
- Creates memory symlink at `~/.claude/projects/<workspace-path>/memory/`.
- Syncs `.agent-skills/` → `.agents/skills/` (Codex skills path).
- Generates `.codex/agents/*.toml` from `.agent-personas/` via `scripts/generate-codex-agents.py`.
- Configures `core.hooksPath` → `.claude/git-hooks`.
- Installs Marky (macOS only, non-fatal).

### Connector-first MCP

Linear, GitHub, Gmail, Notion, Google Calendar, Google Drive → always via claude.ai connectors. Never `.mcp.json`, never manual API keys.
