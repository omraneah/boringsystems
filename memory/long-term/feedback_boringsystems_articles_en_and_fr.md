**Boringsystems is bilingual by default. Every article, playbook, or page-copy update ships in EN and FR together, in the same PR. Never ask Ahmed whether to do French.**

**Why:** boringsystems serves a French-market audience as a primary segment. EN-only or FR-deferred is not on the table. Asking creates friction and signals the rule isn't internalized.

**How to apply:**

- When writing or updating any article, page copy, or playbook for boringsystems: produce EN at `src/content/writing-en/` (or equivalent path for the surface in question) AND FR at `src/content/writing-fr/` (or equivalent).
- Both languages in the same PR.
- Translation is not literal — follow the French voice guide. Always run `/french-audit` on the FR after drafting (see companion long-term rule on review skills).
- If a translation choice is genuinely uncertain (rare technical term, idiom, register decision), flag it in the PR description for Ahmed's call. Do NOT skip FR.
- The only exception: explicit instruction from Ahmed to ship EN-only for a specific reason, which he will provide unprompted. Default behaviour is always bilingual.
