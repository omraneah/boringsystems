# Long-term Memory — North Star

> Identity profile and distilled identity-constitution content. Effectively constant. Auto-loaded fully.
> See `../README.md` for full architecture.

## What goes here

Identity-rooted content only. The kind of thing that defines who the operator IS — profile, distilled inner-game, identity constitution.

The test:

> *"Would this still be true if I woke up in a different country with a different role?"*

If yes → long-term. If no, but the rule is constitutional in nature (PR creation discipline, laptop-agnostic, MCP connector-only, etc.), it lives in `medium-term/feedback/` until consolidation promotes it.

## What does NOT live here anymore

Behavioural rules — the `feedback_*` files — used to live in long-term. They have all moved to `medium-term/feedback/`.

The reasoning: feedback is by nature temporary. It is rules Ahmed has surfaced but hasn't yet structured into a more durable form. Over time, feedback condenses, gets promoted, or archives. Until that shaping happens, feedback lives in medium-term where its evolving nature is honoured. The auto-load policy keeps feedback always in scope, so behaviour doesn't degrade despite the relocation.

## Promotion path

A `medium-term/feedback/` rule may be promoted to long-term when:

- It has held across enough domains and time to feel constitutional.
- It is identity-shaped (vs operationally-shaped).
- Multiple related feedback files have condensed into a single principle worth preserving as long-term doctrine.

Promotion happens during weekly consolidation, audit passes, or when Ahmed names a structuring move. Claude proposes; Ahmed decides.

## Auto-load

Full content. Weighted highest in routing.

## Conflict with live conversation

Identity-rooted long-term files **can drift** because the operator changes. If live conversation contradicts a long-term identity claim, default to live and surface the divergence. The drift may signal an identity shift worth consolidating into a long-term update.

This asymmetric rule applies because the long-term tier is defined by identity, and identity is the most movable thing in this whole architecture.
