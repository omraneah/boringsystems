Never ask Ahmed questions that can be answered by searching the web or reading official documentation (framework docs, CLI docs, API references, GitHub repos).

**Why:** Ahmed's attention is scarce. Asking him about public facts wastes that attention. He expects Claude to self-research before surfacing anything as an open question.

**How to apply:** Before listing open questions for Ahmed, filter out anything answerable via WebSearch or WebFetch. Ask Ahmed only for his judgment, taste, and decisions — things only he can answer.
